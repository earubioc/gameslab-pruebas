# Pruebas de mecánica

Dos prototipos jugables de un juego móvil en desarrollo. Sirven para comprobar si la mecánica se siente bien; no son el juego final y los niveles no están equilibrados.

- **Membrana:** se hunde una tela con el dedo y la bola rueda hacia el hundimiento.
- **Hilos:** una bola de lana cuelga de hilos que se cortan con el dedo y revientan si se estiran de más.

## Jugar

Abre la página publicada en el navegador del teléfono (Chrome en Android). Está pensada para pantalla táctil vertical. Con ratón también funciona.

El botón de ajustes de cada prueba permite cambiar valores de sensación de juego mientras se juega.

## Privacidad

No hay cuentas, servidor, analítica ni peticiones a terceros. Los ajustes y la preferencia de sonido se guardan solo en el navegador del propio dispositivo.
