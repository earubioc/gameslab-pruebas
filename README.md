# Pruebas de mecánica

Prototipos jugables de un juego móvil en desarrollo. Sirven para comprobar si la mecánica se siente bien; no son el juego final y los niveles no están equilibrados.

- **Cubo Cebolla:** las tres ideas juntas en un recorrido por capas, con un puzle de colores como puerta entre capas, estrellas y una colección de aspectos. Es el prototipo más completo.
- **Membrana:** se hunde una tela con el dedo y la bola rueda hacia el hundimiento. Incluye un editor de niveles: se crean, se prueban y se comparten con un enlace o un código corto, sin servidor.
- **Hilos:** una bola de lana cuelga de hilos que se cortan con el dedo y revientan si se estiran de más.

## Jugar

Abre la página publicada en el navegador del teléfono (Chrome en Android). Está pensada para pantalla táctil vertical. Con ratón también funciona.

El botón de ajustes de cada prueba permite cambiar valores de sensación de juego mientras se juega.

## Privacidad

No hay cuentas, servidor, analítica ni peticiones a terceros. Los ajustes, la preferencia de sonido y los niveles creados se guardan solo en el navegador del propio dispositivo. Un nivel compartido viaja entero dentro del enlace o del código; no se sube a ningún sitio.
